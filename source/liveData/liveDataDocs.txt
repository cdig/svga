
Use live sensor data in your application!

Take "LiveData", (liveData) ->

    now you can use liveData methods such as the following:

    === BASIC SETUP ===
    liveData.showConnectionTools()
    liveData.hideConnectionTools()

    === DATA TRANSFER ===
    liveData.getChannel channelName, defaultValueForWhenNotConnected       : Channel name can be a number or a string. Will return the newest value on the channel, will return the default if not connect.
    liveData.sendChannel channelName, valueToSend                          : Sends data back to the LBSConnect software, can be used to control physical systems. Use with caution.

    === ADVANCED (don't use unless you really know what your doing) ===
    liveData.useSignalingHost("http://localhost:4000")                     : Sets the socket.io address of the signaling server to something other than lunchboxsessions.com. If you are going to use it, make sure this is called BEFORE liveData.showConnectionTools()



Internal docs, for SVGA developers: ============
The programs in the liveData directory make "socekt.io", "LiveDataGUI", and "LiveData"
"LiveDataGUI" should never be used by the animators, all of it's public functionality is made public via LiveData
"socket.io" could technically be used in other places, but can't think of a good use case other than this
